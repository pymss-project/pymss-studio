# Audio merge

Concatenate audio files in order with shared output settings.

Version: `0.1.0`. Plugin ID: `pymss.merge`.

Install this directory through Studio's plugin marketplace, or use `pymss install ./plugins/merge` from a local checkout. The built Studio page is `ui/dist/index.html`; edit its source under `ui/src/`. Python processing lives directly under `backend/`.

Operations:

- `pymss.merge.tool`: Audio merge.
