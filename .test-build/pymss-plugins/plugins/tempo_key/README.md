# Tempo and key

Detect tempo and musical key for beat and tonal analysis.

Version: `0.1.0`. Plugin ID: `pymss.tempo_key`.

Install this directory through Studio's plugin marketplace, or use `pymss install ./plugins/tempo_key` from a local checkout. The built Studio page is `ui/dist/index.html`; edit its source under `ui/src/`. This plugin uses the public Studio audio-analysis service.
