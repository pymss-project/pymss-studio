# Audio information

Inspect duration, sample rate, channels and audio encoding.

Version: `0.1.0`. Plugin ID: `pymss.inspect`.

Install this directory through Studio's plugin marketplace, or use `pymss install ./plugins/inspect` from a local checkout. The built Studio page is `ui/dist/index.html`; edit its source under `ui/src/`. Python processing lives directly under `backend/`.

Operations:

- `pymss.inspect.tool`: Audio information.
