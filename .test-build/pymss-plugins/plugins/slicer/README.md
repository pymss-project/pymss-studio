# Audio slicing

Split audio at silent regions and export individual segments.

Version: `0.1.0`. Plugin ID: `pymss.slicer`.

Install this directory through Studio's plugin marketplace, or use `pymss install ./plugins/slicer` from a local checkout. The built Studio page is `ui/dist/index.html`; edit its source under `ui/src/`. Python processing lives directly under `backend/`.

Operations:

- `pymss.slicer.tool`: Audio slicing.
