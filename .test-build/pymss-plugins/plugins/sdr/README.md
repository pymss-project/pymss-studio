# SDR evaluation

Align reference and estimated audio and evaluate SDR and SI-SDR.

Version: `0.1.0`. Plugin ID: `pymss.sdr`.

Install this directory through Studio's plugin marketplace, or use `pymss install ./plugins/sdr` from a local checkout. The built Studio page is `ui/dist/index.html`; edit its source under `ui/src/`. Python processing lives directly under `backend/`.

Operations:

- `pymss.sdr.tool`: SDR evaluation.
